# Simple_Calculator

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Clear / Reset
- 🔢 Decimal number support
- 📱 Responsive design
- 🖥️ Simple and easy-to-use interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and responsive layout
- **JavaScript** – Calculator logic and functionality

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/simple-calculator.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it! 🎉

## 💡 How It Works

The calculator uses JavaScript to handle button clicks and perform arithmetic operations.

For example:

```text
10 + 5 = 15
20 - 8 = 12
6 × 4 = 24
20 ÷ 5 = 4
```
